# Elica Connect for Home Assistant — v0.2.2

Elica Connect is a community custom integration for Home Assistant that brings
Elica Connect hoods and compatible appliances into the Home Assistant UI.

## What it provides

- Fan control with percentage and speed presets.
- Automatic and intensive operating modes.
- Light control and brightness.
- Intensive and auto-off timers.
- Grease filter efficiency monitoring.
- Cloud and MQTT connectivity diagnostics.
- MQTT message statistics.
- Config-flow setup from the Home Assistant UI.

It has been verified with an Elica **BOXIN ADV PLUS IX/A/90** running firmware
**A1**. Other models may work according to the capabilities reported by Elica
Connect; compatibility reports are welcome.

## Installation

Install it from HACS using the repository:

<https://github.com/ricfio/elica-connect-adapter>

Then restart Home Assistant and add **Elica Connect** from **Settings →
Devices & services**.
